DevTune is an AI‑driven search experimentation platform that measures how AI agents such as ChatGPT, Claude, Perplexity and others recommend, cite, and drive traffic to your product. It provides dashboards of AI‑generated insights, leaderboards, and actionable recommendations to improve visibility and conversions. Users can run free trials without a credit card, explore AI‑powered search results, and integrate via its API or MCP to automate data collection and analysis.

**Areas:** Company · AI · Search · Analytics · Platform

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for DevTune: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
